# Fast Expense for iPhone

The native iOS app for [Fast Expense Tracker](https://github.com/Chrisgmsl22/fast-expense-tracker) (FET). It is a Swift app that reads and writes the same data as the web app, through the FET backend.

The repo is public. It holds no real financial data and no secrets. Screens and fixtures use invented demo data.

## Status

Foundation. The agent harness, the docs structure and the design screens come first. There is no Swift code yet.
