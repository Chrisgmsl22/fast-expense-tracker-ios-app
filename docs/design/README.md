# Fast Expense for iPhone — design screens

Every screen of the native iOS app, exported from the **FET** design canvas (pages "iOS app", "iOS app 2 Dashboard" … "iOS app 5 Settings").

- iPhone 390 × 844 pt, PNG @2x (780 × 1688). App Store screenshots are 1320 × 2868.
- Data is the web app's demo data: November 2026, partner Sam, 68/32 split, MXN.
- Each section folder has its own `README.md` with every screen, its badge and the reason for each change.

**Badges:** **Kept** = same as the web phone view · **Adjusted** = same content, native changes only · **New · Brief N** = planned feature from the roadmap · **Proposal** = inferred or undecided, needs a decision.
