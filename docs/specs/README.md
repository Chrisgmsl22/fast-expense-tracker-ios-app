# Specs

One spec per feature area. A spec says what the area does and why, for a reader who was not
in the conversation. It outlives the work. The order of work goes in `docs/plans/`, not
here.

Name a spec `NNNN-short-name.md` with the next free number. Rules:
[`doc-structure.md`](../conventions/doc-structure.md).
